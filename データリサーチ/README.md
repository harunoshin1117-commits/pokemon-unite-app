# ポケモンユナイト データリサーチ

最終更新日: 2026-06-14

## 目的

このフォルダは、ダメージ計算サイトへ採用する前の調査データを保管する場所です。

- `researchData.json`: 出典、競合、不明点、人間による確認状況を含む研究用データ
- `pokemonData.js`: アプリが計算に使う最小限の採用済みデータ

研究用データとアプリ用データを分離し、不確かな値が自動的に計算へ使われないようにします。

## データ状態

### confirmed

公式が具体的な値を公開しているか、ゲーム内検証で確認できた値です。

### candidate

出典がある採用候補です。人間による最終確認は完了していません。

### conflict

複数の候補値が食い違っています。人間が採用値を決めるまでアプリへ自動反映しません。

### unknown

根拠のある値を特定できていません。`0` や推測値で補いません。

## アプリへの採用条件

次のどちらかを満たした項目だけを `pokemonData.js` へ移します。

1. `status` が `confirmed`
2. `status` が `candidate` で、`approvedForApp` が `true`

どちらの場合も、以下を満たす必要があります。

- `value` が `unknown` ではない
- 未解決の `conflicts` がない
- `normalizedFormula` が必要な項目では、元の式との対応を確認済み

## candidateの仮採用

名前、技スロット、習得レベルなどは、信頼できる出典があり、人間が承認すれば `candidate` のまま仮採用できます。

計算結果へ直接影響するステータス、式、ヒット数も仮採用できますが、必ず `approvedForApp: true` を人間が設定します。

## conflictとunknown

- `conflict`: 自動変換しない。候補を残し、人間が解決する。
- `unknown`: 自動変換しない。必須値ならその計算を未対応にする。
- 既存アプリの値は出典ではなく、比較対象の `localData` として扱う。

## researchDataからpokemonDataへの変換手順

1. JSON形式と必須項目を検証する。
2. `conflict` と `unknown` を除外する。
3. `confirmed` または承認済み `candidate` を抽出する。
4. 元の式と正規化した式の対応を確認する。
5. `_labelJa`、`sources`、`conflicts`、`verifiedByHuman` などの研究情報を除く。
6. アプリ用データへ変換する。
7. 計算テストを実行する。
8. 人間が差分を確認して採用する。

## ピカチュウの確認順

### 優先度A

- レベル1・5・9・13・15の主要ステータスと急所率   ok
- 通常攻撃が防御を参照するか      ok
- 強化攻撃が特防を参照するか      ok
- 2026年5月14日調整後の各技式
- かみなりの通常5ヒット、プラス7ヒット
- ボルテッカーの5ヒット
- フルボルトストームの対象別ヒット数

### 優先度B

- エレキボールの減少HP6％・8％
- エレキボール追加ダメージの防御補正
- 各ヒットの丸め位置
- 各技の急所可否

### 優先度C

- ボルテッカーの正式な日本語表記
- 各技の日本語説明
- まひ、移動不能、スタン時間

## 注意

このフォルダの内容は採用候補です。最終判断は人間が行います。
