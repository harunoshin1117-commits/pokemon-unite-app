# Pokemon Unite Damage Calculator

ポケモンユナイトのダメージ検証をブラウザ上で行うための静的Webアプリです。

単なるダメージ計算だけでなく、将来的にはゲーム内の練習場で行う検証作業を、ブラウザ上で再現・記録・比較できる検証サイトへ発展させる方針です。

## 公開URL

https://harunoshin1117-commits.github.io/pokemon-unite-app/

## 現在の主な機能

- 攻撃側ポケモン、防御側ポケモン、レベルの選択
- 攻撃側ポケモン要約カード
- 攻撃側の現在HPバー操作と数値入力
- 攻撃側特性の説明表示
- 持ち物選択
- 通常攻撃、技セット1、技セット2、ユナイト技のダメージ計算
- 通常攻撃の急所結果固定
- 技の使用回数指定
- 防御・特防を考慮した最終ダメージ計算
- 合計ダメージと残りHP表示
- 通常攻撃の1ヒットごとの詳細表示
- 名前付きビルドの複数保存、読み込み、削除
- 保存ビルド内容の確認表示
- スマホ向け下部タブUI
- スマホ、タブレット、PC向けのレスポンシブ表示

## 現在登録しているポケモン

- ピカチュウ
- ゲッコウガ
- エースバーン

一部データは検証中です。未確認の仕様は、確定値として扱わず調査データやドキュメント側で状態を分けて管理します。

- HTML
- CSS
- JavaScript
- ES Modules

- GitHub Pages

## 主要ファイル

- `index.html`: 画面構造
- `style.css`: PC、タブレット、スマホの見た目
- `js/app.js`: アプリ全体の接続、状態管理、イベント処理
- `js/pokemonData.js`: ポケモン、ステータス、技、表示用特性データ
- `js/damageCalculator.js`: ダメージ計算
- `js/resultRenderer.js`: 計算結果の描画
- `js/domElements.js`: DOM取得の集約
- `js/build/`: 保存ビルド機能
- `tests/`: Node標準テスト
- `docs/project-map.md`: 作業開始時に最初に読む入口
- `docs/project-overview.md`: 現在の構成、設計メモ、改善履歴
- `docs/roadmap.md`: 思いついたアイデアや将来方針の保管場所

## 開発時によく使うコマンド

```bash
npm test
```

```bash
npm run stats -- Pikachu 13
```

`npm run stats` は `pokemonData.js` のステータス確認用です。行番号で巨大データを読むと別ポケモンの値を誤読しやすいため、ステータス確認ではこのコマンドを使います。

## 開発方針

- 既存UIと計算結果を不用意に変えない
- 変更は小さく進める
- 計算処理は、できる限りゲーム内の実際の挙動に近づける
- 未確認の仕様は推測で確定しない
- 実測値、出典、検証状態を分けて記録する
- 大きな設計変更、削除、ファイル移動の前に確認する
- 構成や主要関数を変更した場合は `docs/project-overview.md` を更新する

## 調査データについて

ポケモンや技の仕様は、アプリ用データと調査用データを分けて管理しています。

調査データでは、候補値、出典、矛盾、不明点、人間確認状態を残し、最終採用前の値を確定済みとして扱わない方針です。

特殊効果の横断調査や検証メモは `docs/` と、リポジトリ外の `データリサーチ` フォルダに分けて保存しています。

## 注意

このアプリは開発中です。現在の計算結果には、ゲーム内検証済みのものと、外部データをもとにした候補段階のものが混在しています。
