# ポケモンユナイト ダメージ計算アプリ

ポケモンユナイトの技ダメージを計算できるWebアプリです。

## 公開URL

https://harunoshin1117-commits.github.io/pokemon-unite-app/

## 主な機能

- ポケモン選択
- レベル選択
- 技選択
- ヒット数選択
- 防御・特防を考慮した最終ダメージ計算
- 残りHP表示
- HPバー表示
- 合計ダメージ表示

## 使用技術

- HTML
- CSS
- JavaScript
- Git
- GitHub
- GitHub Pages

## 使い方

1. 自分のポケモンを選択
2. レベルを選択
3. 技を選択
4. 相手ポケモンを選択
5. ダメージを確認
