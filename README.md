# Pokemon Unite App

ポケモンユナイトのダメージ計算とゲーム内検証を、ブラウザ上で再現・記録・比較できるようにするための開発リポジトリです。

このリポジトリは、アプリ本体だけでなく、ポケモンや技の調査データ、人間確認用の検証メモ、補助ツールもまとめて管理します。GitHubやChatGPT/Codexから読むときは、このREADMEを入口にしてください。

## 公開URL

GitHub Pagesで公開する場合、現在のアプリ本体は `ポケモンユナイト/` 配下にあります。

ルートを外側へ広げたため、GitHub Pagesの公開設定や表示URLは必要に応じて確認してください。

## フォルダ構成

```text
pokemon-unite-app/
├─ ポケモンユナイト/    アプリ本体
├─ データリサーチ/      ポケモン・技・特殊効果の調査データ
├─ 人間確認用/          ゲーム内検証メモ、確認用HTML、テンプレート
└─ tools/               補助ツール置き場
```

## アプリ本体

`ポケモンユナイト/` がブラウザで動作するダメージ計算アプリ本体です。

主な内容:

- 攻撃側・受ける側ポケモン、レベル、持ち物の選択
- 攻撃側ポケモン要約カード
- 攻撃側の現在HPバーと手入力
- 通常攻撃、技セット、ユナイト技のダメージ計算
- 通常攻撃の急所結果固定
- 保存ビルド機能
- スマホ向けタブUI
- 特性表示欄

詳しくは以下を参照してください。

- `ポケモンユナイト/README.md`
- `ポケモンユナイト/docs/project-map.md`
- `ポケモンユナイト/docs/current-status.md`
- `ポケモンユナイト/docs/ai-workflow.md`
- `ポケモンユナイト/docs/project-overview.md`
- `ポケモンユナイト/docs/roadmap.md`

## 調査データ

`データリサーチ/` には、ポケモンごとのステータス、技、特殊効果、検証状態、出典、未確認事項を保存しています。

調査データはアプリへそのまま反映する確定データではありません。候補、矛盾、不明点、人間確認待ちの情報も含めて管理します。

## 人間確認用

`人間確認用/` には、ゲーム内検証を記録するためのHTML、テンプレート、補助スクリプトを置いています。

検証値は、計算式や処理順を決める前の根拠データとして扱います。

## 補助ツール

`tools/` は補助ツール置き場です。

動画解析など重いローカル実験ツールはGit管理から除外する方針です。現在 `tools/damage-video-review/` は `.gitignore` で除外しています。

## 今回行った主な調整

- Git管理ルートを `ポケモンユナイト/` から `pokemon-unite-app/` へ拡張
- `データリサーチ/` と `人間確認用/` をGitHubから参照できる構成へ変更
- 外側ルート用の `.gitignore` を追加
- 動画、生成画像、仮想環境、zip、出力フォルダをGit管理から除外
- 外側ルート用の `.gitattributes` を追加
- テキストファイルの改行をLFへ統一する方針に変更
- 日本語フォルダを含むリポジトリ全体をAIが読みやすい構成へ整理

## Git管理方針

Git管理するもの:

- アプリ本体
- 調査JSON/Markdown
- 人間確認用HTML/テンプレート
- 軽量な補助スクリプト

Git管理しないもの:

- 動画ファイル
- 生成画像
- 仮想環境
- `node_modules/`
- `tools/damage-video-review/`
- zipなどのアーカイブ
- 生成された `output/` フォルダ

## 開発方針

- ゲーム内で実際に出るダメージ再現を重視する
- 未検証情報を確定値として扱わない
- 調査データとアプリ実装データを分ける
- 変更は小さく進める
- 大きな設計変更、削除、ファイル移動の前に確認する
- 構成や主要関数を変更したら関連ドキュメントを更新する

## 開発時によく使うコマンド

アプリ本体のコマンドは `ポケモンユナイト/` で実行します。

```bash
cd ポケモンユナイト
npm test
```

```bash
cd ポケモンユナイト
npm run stats -- Pikachu 13
```

## 注意

このプロジェクトは開発中です。計算結果には、ゲーム内実測済みのもの、候補式、未検証の仮説が混在しています。

不明点や矛盾は隠さず、調査データやドキュメントに残す方針です。
