# Pokemon Unite App Roadmap

最終更新日: 2026-06-14

## このファイルの目的

このファイルは、思いついた機能や改善案を忘れないように保管する場所です。

ここに書かれた内容は、実装予定や確定仕様を意味しません。実装方法、優先順位、影響範囲は、実際に作業するときに改めて検討します。

## 運用ルール

- 思いついたアイデアは、仕様が決まっていなくても記録する。
- 説明は、後から内容を思い出せる程度でよい。
- 優先順位や実装手順は、このファイルでは管理しない。
- 実装済みになったアイデアは、このファイルから削除するか、実装済みと短く記録する。
- 実装するときは、既存UI、計算結果、保存データへの影響を別途確認する。

## アイデアの記録形式

```md
### IDEA-001: 機能名

- 内容:
- メモ:
```

## 保管中のアイデア

### IDEA-001: 攻撃側メダル

- 内容: 攻撃側が装備するメダルの選択、ステータス補正、保存データへの追加を検討する。
- メモ: 固定値と割合補正の適用順、端数処理は実装時に確認する。

### IDEA-002: 受ける側の持ち物・メダル

- 内容: 受ける側の持ち物とメダルを選択し、防御・特防やその他の効果へ反映する。
- メモ: 攻撃側の保存ビルドと防御側データは分けて扱いたい。

### IDEA-003: シールド・共鳴ガード

- 内容: シールド値をHPとは別に保持し、ダメージをシールドから先に消費する。共鳴ガードなどのシールド生成も同じ仕組みで扱う。
- メモ: シールドはHPへ加算せず、別の値として扱う。

### IDEA-004: 与ダメージ・被ダメージ倍率補正

- 内容: 与ダメージ倍率と被ダメージ倍率を分けて入力・計算する方法を検討する。
- メモ: 倍率の適用順と丸め位置は実装時に決める。
